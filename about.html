🚨 About Silent Emergency Alert System

The Silent Emergency Alert System is a web-based safety application designed to help users quickly respond during emergency situations without attracting attention.

🎯 Project Objective

To provide a fast, secure and silent way for users to trigger emergency alerts and simulate safety response actions through a simple web interface.

⚙️ How It Works

1. User logs into the system using username and password.
2. User accesses the dashboard after login.
3. In emergency, user clicks “SOS Button”.
4. System shows alert message (simulation of emergency signal).

💡 Features

✔ Login & Registration System
✔ Dashboard Interface
✔ Emergency SOS Button (Simulation)
✔ Clean and Responsive UI
✔ Secure Navigation Flow
